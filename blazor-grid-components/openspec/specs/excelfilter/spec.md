## Purpose

The Excel filter domain defines how the grid renders and executes Excel-style filtering for a column. It combines checkbox-based distinct value selection, in-popup search, and custom operator/value dialogs. It also defines filter dialog event hooks, adaptive/mobile rendering, and JS interop used for popup positioning and focus.

## Requirements

### Requirement: Excel Filter Type Activation

The grid SHALL activate Excel filter UI when `GridFilterSettings.Type` or per-column `GridColumn.FilterSettings.Type` resolves to `FilterType.Excel`.

#### Scenario: Rendering Excel filter component
- **GIVEN** filtering is enabled and the active filter type for the clicked column resolves to `Excel`
- **WHEN** the filter icon is clicked and the filter layer is rendered
- **THEN** the grid renders `FilterCheckBoxRenderer<TContent>` and includes `ExcelBase<TContent>` in the popup content

### Requirement: Filter Dialog Open Lifecycle

Before opening an Excel filter popup, the grid MUST run cancellable opening hooks and SHALL stop opening if cancellation is requested.

#### Scenario: Cancel opening from event args
- **GIVEN** a column filter popup open is requested for an Excel filter column
- **WHEN** `FilterDialogOpening` or `OnActionBegin` (`RequestType = FilterBeforeOpen`) sets `Cancel = true`
- **THEN** the popup is not shown and `FilterIconIsClicked` is reset through filter component update flow

### Requirement: Excel Distinct Choice Data

The Excel filter popup SHALL build selectable distinct values from the column data and MAY be overridden by custom `CheckboxListData` or `FilterChoiceCount` from opening/search events.

#### Scenario: Default and custom choice counts
- **GIVEN** an Excel filter popup is opening
- **WHEN** no custom count is provided
- **THEN** up to 1000 distinct values are shown; otherwise the provided `FilterChoiceCount` is applied

### Requirement: Excel Search Behavior

Excel popup search SHALL trigger filter search events and MUST update list items based on parsed input and operator context.

#### Scenario: Search in checkbox/excel popup
- **GIVEN** an Excel filter popup is open
- **WHEN** the user types in the search input
- **THEN** the grid raises `OnActionBegin` with `RequestType = FilterSearchBegin`, raises `CheckboxFilterSearching`, applies returned `SearchText`/`CheckboxListData`, and refreshes visible choices

### Requirement: Excel Apply Behavior

Applying Excel filtering SHALL update `GridFilterSettings.Columns` and MUST raise filtering model-change flow with generated predicates.

#### Scenario: Apply selected values
- **GIVEN** the user has selected a subset of values in the Excel popup
- **WHEN** the user clicks the primary action button
- **THEN** the grid removes existing predicates for the same column UID, generates `equal`/`notequal` predicates as implemented, updates `FilterSettings.Columns`, and invokes model change with `RequestType = Filtering`

### Requirement: Excel Custom Filter Dialog

Excel filter SHALL support custom operator/value filtering via submenu (`Custom Filter` and `Between`) using one or two predicates.

#### Scenario: Apply custom filter from Excel submenu
- **GIVEN** the user opens Excel submenu and selects `Custom Filter` or `Between`
- **WHEN** the user confirms values/operators in the custom dialog
- **THEN** the grid applies one predicate when only one operand is valid, or two predicates with selected conjunction (`and`/`or`) when both operands are provided

### Requirement: Excel Clear and Close Semantics

Excel clear and close actions MUST synchronize popup, filter icon, and column predicates according to implemented flow.

#### Scenario: Clear action in Excel popup
- **GIVEN** an Excel filter popup is open for a column
- **WHEN** the user clicks the clear/cancel action
- **THEN** the popup closes and component state resets, and predicate removal is executed according to filter type/adaptive path logic in `ClearBtnClick`

### Requirement: JS Interop for Excel Popup UX

The Excel filter popup SHOULD use JS interop hooks for placement and focus behavior.

#### Scenario: Position and focus during open
- **GIVEN** Excel popup rendering begins
- **WHEN** popup creation/open runs
- **THEN** the grid invokes JS methods including `filterPopupRender`, `customFilterDialog`, and `focusExcelInput` to align popup and focus search input
